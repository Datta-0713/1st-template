# ABYSS media sources

The prototype uses ocean footage hosted by NOAA Ocean Exploration. NOAA states that video in its Ocean Exploration Video Portal is public domain and asks users to include the credit information associated with each item. These direct MP4 sources are used by the prototype as remote lazy-loaded videos.

- Glass Squid — NOAA Ocean Exploration, Deep-Sea Symphony: Exploring the Musicians Seamounts
  https://oceanexplorer.noaa.gov/multimedia/video-shorts-ex1708-glass-squid/
- A Midwater Exploration — NOAA Ocean Exploration, Deep Connections 2019
  https://oceanexplorer.noaa.gov/multimedia/video-playlist-column-midwaterex/
- Hiding in the Dark — NOAA Ocean Exploration, Deep-Sea Symphony: Exploring the Musicians Seamounts
  https://oceanexplorer.noaa.gov/multimedia/video-playlist-ex1708-hiding-dark/
- No Boundaries — NOAA Ocean Exploration, Deep Connections 2019
  https://oceanexplorer.noaa.gov/multimedia/okeanos-explorations-ex1905-dailyupdates-videos-no-boundaries-no-boundaries/
