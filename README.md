# ABYSS Ocean Intelligence — refined prototype

This prototype keeps the existing scroll choreography and adds a more cohesive ABYSS visual/motion system: restrained depth parallax, cinematic media transitions, video-to-color bridge bands, adaptive accordion panels, mobile-specific scrollytelling flow, glass navigation states, and responsive interaction fallbacks.

## Media
The prototype lazy-loads several public-domain NOAA Ocean Exploration videos as remote sources. See `MEDIA-SOURCES.md` for attribution and source pages. Replace these remote URLs with your own generated/owned media for final deployment.

## Run
Open `index.html` in a browser, or serve this folder with any static HTTP server so video loading and browser policies behave normally.
